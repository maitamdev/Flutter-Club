# Button Component

## Usage
```tsx
import { Button } from '@/components/ui/button';
<Button variant='default'>Click Me</Button>
```

## Variants
- default, secondary, destructive, outline, ghost, link

## Props
| Prop | Type | Default |
|------|------|---------|
| variant | string | 'default' |
| size | string | 'default' |
| disabled | boolean | false |
